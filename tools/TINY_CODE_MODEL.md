# 자비스 초소형 코드 모델 v1

## 이 모델이 하는 일
- 외부 사전학습 모델 없이 무작위 가중치에서 NumPy로 학습한 문자 단위 신경망입니다. 임베딩과 은닉층을 사용하는 38,381 파라미터 MLP이며, 이전 16자에서 다음 글자를 예측합니다.
- 사이트의 `자비스 코딩 모델 보고`, `자비스 코드 자동완성 function add(a,b){return` 명령으로 실험합니다. 한글 지시 이해·문제 해결·테스트 후 수정이 아닙니다. 생성 코드는 자동 실행하지 않습니다.
- 영문·숫자·일반 기호로 구성된 코드만 입력할 수 있습니다. 첫 사용에 약 391 KB 모델 파일을 불러오며, 서비스 워커에 캐시된 뒤에는 오프라인에서도 사용할 수 있습니다. 첫 사용 때 오프라인이면 사용할 수 없습니다. 브라우저 캐시가 삭제되거나 서비스 워커가 갱신되면 다시 다운로드해야 할 수 있습니다.
- 출처: `code-corpus.json`의 `trekhleb/javascript-algorithms`, revision `85293e3e2b88f4d2ce330d956b139cf628aa1e82`, MIT. 라이선스 원문은 `third-party/javascript-algorithms-LICENSE.txt`에 있습니다.

## 재현
Python 3와 NumPy가 필요합니다. 패키지 설치나 외부 모델 다운로드는 하지 않습니다.

```
OPENBLAS_NUM_THREADS=1 python3 tools/train_tiny_code_model.py --steps 12000 --batch 128
OPENBLAS_NUM_THREADS=1 python3 tests/tiny-model-metrics.test.py
OPENBLAS_NUM_THREADS=1 python3 tools/assess_tiny_code_model.py
node tests/tiny-code-model.test.js
```

고정 seed와 파일 내용 해시를 사용하고, 알고리즘 폴더 단위로 train/validation/test 그룹을 분리합니다. 정확히 같은 전체 파일은 중복 제거합니다. 코드 자료는 동일 저장소에서 왔으므로 파일 간 유사한 패턴이 남을 수 있으며 완벽한 중복·의미 중복 제거를 보장하지 않습니다. 분할 및 파일 해시 목록은 `tiny-code-training-report.json`에 기록되어 있습니다. 테스트 16,000개 위치는 최종 가중치 평가에 사용했으며 최종 공개 전에도 초기 모델과 비교했습니다. 검증 지표는 훈련 도중 주기적으로 확인했습니다. 실험 설정 변경에 따라 테스트가 반복 활용되면 신선한 새로운 평가 세트를 별도로 만들어야 합니다.

학습 후 테스트의 다음 문자 정확도는 무작위 초기값 0.8563%에서 57.675%로 개선되었습니다. 단순히 이전 글자 한 개만 이용하는 빈도 기준은 30.6312%, 공백을 제외한 모델 정확도는 50.0634%입니다. 이 수치는 **다음 글자 예측**이지 완성된 함수의 정답률이 아닙니다. 독립적인 8개 손수 작성 프롬프트에서 길이 64의 탐욕적 자동완성을 만든 후 `node --check`로 구문만 검사하면 1개가 통과했으나, 통과한 예도 공백만 추가된 빈 함수로, 정답이라고 볼 수 없습니다. 실제 생성·테스트·수정 능력은 이 시험에서 입증되지 않았습니다.

`assess_tiny_code_model.py`는 생성 결과를 Node 구문 검사만 하며 실행하지 않습니다. 훈련 데이터와 유사한 코드 조각을 재현할 수 있으므로 저작권과 출처 표시에 주의하세요. 휴대폰에서의 사용감과 실제 Galaxy A17 하드웨어 성능은 별도로 확인해야 합니다.
