# 자비스 코딩 요청 신경망 v1 (실험)

## 무엇을 학습했나
- 사용자 요청의 문자 단위 1·2-그램 특징과 앞서 생성한 코드 24자를 입력으로 다음 코드 문자를 예측하는 **조건부 MLP**입니다. 외부 사전학습 모델 없이 무작위 초기값으로 시작하며 83,296개 파라미터를 직접 업데이트합니다. Transformer나 대화형 대형 언어 모델은 아닙니다.
- 1단계: `code-corpus.json`의 JavaScript 297개 훈련 파일, 약 60만 개 문자 위치로 다음 글자 예측을 학습했습니다. 출처 `trekhleb/javascript-algorithms` revision `85293e3e2b88f4d2ce330d956b139cf628aa1e82`, MIT. 라이선스: `third-party/javascript-algorithms-LICENSE.txt`. 개행과 탭은 공백으로 정규화하고 ASCII에 없는 글자는 `?`로 취급했습니다. 알고리즘 폴더를 train/validation/test로 분리하되 같은 저장소의 유사 코드가 남을 수 있습니다.
- 2단계: 직접 작성한 한국어 코딩 요청 120개와 10개의 아주 짧은 JavaScript 정답 함수로 지도 학습했습니다. 데이터와 분할: `training/code-instructions.json`. 정답 코드 10개가 훈련 예시에 여러 번 등장합니다. 생성은 가중치의 문자 예측을 반복하는 것이며 코드 목록을 선택하거나 복사하는 방식으로 구현하지 않았습니다. 그렇더라도 훈련 정답을 그대로 재현할 수 있고, 이 실험으로 새로운 알고리즘을 이해했다고 볼 수 없습니다.
- 일반적인 문맥 대화나 미학습 문제 해결 모델이 아닙니다. 사용자 요청에 대한 코드가 틀릴 수 있으며, 결과는 자동 실행·검증·자가 수정하지 않습니다.

## 검증과 한계
코드 자료의 별도 시험 41개 파일에서 뽑은 12,000개 문자 위치의 크로스 엔트로피는 초기 **4.579 → 코드 선행 학습 후 1.772 → 요청 학습 후 3.068 nats**였습니다. 낮을수록 좋습니다. 요청 학습 후 코드 예측력이 일부 떨어진 것을 숨기지 않습니다. 같은 시험 세트는 이전 코드 모델 실험에서도 활용했으므로, 차후 개선에는 새로운 별도 데이터가 필요합니다.

한국어 요청의 훈련 예제 120개, 검증 예제 20개, 일차 테스트 30개는 각각 다른 문장입니다. 유형 10개와 정답 코드는 모두 같습니다. 검증 예제로 체크포인트를 선택했습니다(20,000회 훈련 중 4,000번째 선택). 30개 테스트 요청 중 문자열까지 완전히 일치한 코드는 초기 0개에서 30개로 늘었습니다. **표현이 훈련 요청과 비슷하므로 일반화 능력 점수라고 볼 수 없습니다.**

일치한 30개 코드에 20개씩 별도 입력을 적용해 600/600 통과했습니다. `tools/test_instruction_semantics.py`는 생성 결과가 감사된 정답 문자열과 정확히 일치하는 경우만 실행합니다. 임의로 생성된 JS는 실행하지 않습니다. 검사값은 독립적인 Python 참조 결과와 비교했습니다. 유한한 검사는 정답을 보증하지 않습니다.

추가적인 표현 20개는 완전 일치 13/20, 최종 가중치가 결정된 후 새로 작성한 추가 표현 20개는 14/20이었습니다. 첫 추가 세트는 코드 선행 학습을 덧붙이기 전 실험에서 이미 결과를 확인했습니다. 종류 자체가 훈련에 없는 새 문제 4개는 0/4였고, 틀린 코드도 생성했습니다. 새 문제는 작은 수제 샘플이라 전체 성능을 대표하지 않습니다. 이 예제를 다음 훈련에 활용하거나 결과에 맞춰 설계를 고치면 별도로 새로운 시험 세트가 필요합니다. 전체 예제 및 결과는 `training/instruction-evaluation.json`에 있습니다.

## 사이트에서
- `자비스 코딩 학습 보고`
- `자비스 코딩 요청 두 숫자를 더하는 함수를 만들어줘`

첫 호출에 모델 파일 약 846KB가 필요합니다. 온라인 첫 사용 후 서비스 워커 캐시가 유지되면 오프라인 사용이 가능합니다. 캐시가 삭제되거나 앱 버전이 갱신되면 다시 다운로드해야 할 수 있습니다. 모바일 브라우저 모의 시험은 실제 Galaxy A17 성능을 보장하지 않습니다.

## 재현
Python 3, NumPy, Node.js 필요. 학습 중 외부 AI 호출은 없습니다.

```
OPENBLAS_NUM_THREADS=1 python3 tools/train_instruction_model.py --pretrain-steps 12000 --steps 20000
OPENBLAS_NUM_THREADS=1 python3 tests/instruction-model.test.py
OPENBLAS_NUM_THREADS=1 python3 tools/test_instruction_semantics.py
node tests/instruction-model.test.js
```
